# ClipCut

Простой видеоредактор для Windows: обрезка и нарезка, кадрирование, поворот, скорость, звук, цвет, плавные переходы. Экспорт в MP4 (H.264/H.265), WebM, GIF и MP3 с разрешением до 4K и частотой до 60 FPS, с аппаратным ускорением NVIDIA, AMD и Intel.

## Скачать

Установщик — в разделе [Releases](../../releases/latest): файл `ClipCut-Setup-1.0.1.exe`.

Установщик не подписан, поэтому Windows может показать «Windows защитил ваш компьютер». Нажмите «Подробнее», затем «Выполнить в любом случае».

## Сборка

Нужны Node.js, `makensis` (NSIS) и `ffmpeg.exe` для Windows в папке `bin/`.

```bash
npm install
npm run dist
```

Готовый установщик появится в `dist/`.

## Горячие клавиши

Пробел — воспроизведение, ←/→ — по кадрам, I/O — начало и конец фрагмента, S — разрезать, Delete — удалить фрагмент, Ctrl+Z/Ctrl+Y — отмена и повтор, Ctrl+E — экспорт.
